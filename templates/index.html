Methodology & Statistical Notes

Understanding the data hygiene, correlation weights, and projection formulas behind this dashboard.

How is the estimated final exam score computed?

The estimator uses an empirically-weighted formula derived from the dataset's correlation matrix. The baseline score is driven by the three strongest factors: Quiz Average (45%), Midterm Score (35%), and Previous GPA (20%). Habit adjustments (study hours, attendance, assignments, sleep, and internet access) are then added using half-weight damping to reflect observed cohort averages while preventing multicollinearity double-counting.

Why is there a 95% Confidence Interval (±8.5 points)?

In observational academic datasets, human exam performance involves natural variance. Based on the residual standard error (Se ≈ 12.8) of this 4,000-student dataset, the 95% prediction interval indicates the likely score band for 19 out of 20 students with your profile under standard exam conditions.

How were missing values and outliers handled?

Numeric variables with missing values (such as Previous GPA, Sleep Hours, Midterm Score) were imputed using their respective medians to remain robust against skewness and outliers. Categorical fields (Gender and Internet Access) were imputed using the mode (most frequent value).

Why is this dashboard built with zero JavaScript?

All data charts (bar charts, normal distribution bell curve, trend lines, score ring, and multi-factor radar chart) are generated dynamically on the server in Python as pure vector SVGs. This delivers instant page rendering, zero client-side tracking, universal browser compatibility, and minimal network overhead.
